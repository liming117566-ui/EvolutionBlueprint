局域网测试地址为 `http://10.12.195.41:3002`，开发者工具仍用 `http://127.0.0.1:3002`。当前服务监听 `0.0.0.0:3002`，由 `artifacts/devtools/start-backend.cjs` 启动。服务端只接受回环连接，或显式开启 LAN_TEST_AUTH 后的私有 IPv4 连接，不信任转发地址；生产配置禁止启用任一测试开关。体验版和正式版不显示测试入口。关闭测试模式后恢复真实微信登录流程。

## 学习权限

板块名称、简介允许浏览，学习内容须登录并兑换。未兑换时，首页和学习空间显示“兑换后学习”，进入指定板块会打开对应兑换页。原生课程、原有三个网页、新增十一个网页及后台上传的网页均检查服务端权限。

后台“卡密与核销 → 生成新批次”提供三种范围：

- 指定板块：选择一个或多个板块，仅授权这些板块；原生课程板块同时授权关联分类内已发布课程和资料。
- 全部板块与课程：授权所有已发布板块及课程，也覆盖后续新增并发布的内容。
- 指定课程：保留旧卡密兼容性，只授权指定课程；关联板块入口可进入，其他课程仍按原范围鉴权。

兑换截止时间限制卡密核销时间。权益天数从每位用户实际兑换时间起算，留空为长期。卡密只能由一个账号核销，同一账号重试不会重复发放权益。后台数据库和日志保存摘要、掩码，明文仅在创建成功时返回一次，可立即复制或下载 TXT。

权限到期或撤销、退出登录、账号停用，以及板块下架或修改页面类型后，现有网页资源请求也会重新受阻。仅隐藏按钮不能代替这些服务端校验。

## 上传网页与资料

原 PDF / Word 资料继续通过“资源库”上传，在“课程资料”关联课程、章节或小节。

上传网页的步骤：

1. 后台打开“学习网页”，点击“上传网页”。
2. 填写名称，选择单个 HTML / HTM，或包含唯一 `index.html` / `index.htm` 的 ZIP。ZIP 可包含一层外部目录，资源使用相对路径。
3. 在“学习板块”新增或编辑板块，在“打开页面”选择刚上传的网页。
4. 保存草稿，再发布。仅保存草稿不能让学员访问网页。
5. 在“卡密与核销”选择该板块生成兑换码，或使用全部范围兑换码。

单 HTML 最大 5 MiB；ZIP 最大 50 MiB，展开后最大 100 MiB、3000 项。支持静态 HTML、CSS、JavaScript、图片、字体及音视频。服务端程序、路径穿越、符号链接、压缩炸弹和危险文件类型会被拒绝，上传失败会回滚文件。当前或历史发布版本引用的网页不能直接删除。

上传网页在隔离沙箱中运行，支持页面内交互、表单及下载。联网 API、浏览器存储、需要服务器运行的应用不支持；需要这些功能的完整应用应按现有学习模块方式进行源码适配。网页上传不会自动转换或打包服务器应用。

## 网页入口机制

`POST /api/boards/:id/open` 使用小程序登录凭证验证板块权益，返回 60 秒有效的临时入口。URL 不携带 API Bearer 凭证。

微信开发者工具会用桌面和手机上下文先后预检入口，因此 `GET /web-access/:ticket` 只返回跳板，不消耗票据。跳板再向同源 `POST /web-session` 交换一次性票据，设置 HttpOnly、SameSite=Lax、限定资源路径的 Cookie 后跳转。恶意来源、重复交换和过期票据均会被拒绝。网页资源禁止离线缓存；旧英语和数学模块的 Service Worker 与公共离线缓存已停用，原 localStorage 学习记录保留。
