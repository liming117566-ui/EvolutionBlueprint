# 课程新增、发布与前端排序

本地后台入口：<http://127.0.0.1:3002/admin/>。侧栏保留学习板块、完整内容编辑、资源、学员权益、卡密和审计等功能。

## 新增课程

在“工作台”或“内容与发布”点击“新增课程”，选择课程类型：

| 类型 | 如何提供内容 | 单文件限制 |
| --- | --- | --- |
| 在线图文 | 直接录入文字；每行保存为一个段落，后续在“编辑课程”调整章节、小节和练习 | 正文最多 50,000 字符 |
| PDF / Word | 上传 PDF、DOC、DOCX，或从资源库选用已上传文件 | 20 MiB |
| 视频课程 | 上传 MP4、WebM，或选用已上传视频；推荐 H.264 / AAC 的 MP4 | 500 MiB |
| 网页课程 | 上传 HTML 或构建后的静态网页 ZIP，或选用已有网页资源 | HTML 5 MiB；ZIP 50 MiB |

填写课程名称和介绍，选择已有课程主题、已有学习板块，或新建主题与板块。新建板块可选择是否显示在首页，并设置放在最前或末尾。网页课程使用独立的板块入口。

点击“创建课程草稿”后，会自动创建课程与学习入口，并关联上传的文档或视频。点击“编辑课程”可继续编辑章节、小节正文、练习、图片等。在线文字可与课程资料组合使用；Word 按文档方式打开，不会自动转换为可编辑正文。

网页 ZIP 需包含唯一的 `index.html`，图片、脚本和样式使用包内相对路径。现有 Vue、React 等工程应先生成静态构建产物，再打包上传；需要服务端进程的工程不属于静态网页包。

## 发布到前端

创建和编辑课程先进入草稿。点击“保存草稿”保存后，再点击“发布到前端”并确认。发布会同步当前全部目录草稿，包括课程内容、板块显示和排序；学员重新加载前端后看到更新。

上传失败可按提示修改后重试；文件上传成功但课程创建失败时，文件保留在资源库，可通过“从已上传资源中选择”继续创建。

## 调整顺序

打开“前端排序”，选择调整范围：

- **学习板块**：调整首页与学习页入口的顺序，并设置启用、首页、学习页和主推荐开关。
- **课程主题**：调整课程主题显示顺序。
- **主题内课程**：先选择主题，再调整该主题下的课程顺序。

可拖动条目，也可点击“上移”“下移”；手机端可使用上下移动按钮。完成后保存草稿，再发布到前端。章节和小节的顺序在“编辑课程”中调整。

## 资料与权益

“课程资料”可以把文档或视频关联到课程、章节、小节，并设置独立的资料标题、顺序和上架状态。资料关联和上下架独立保存；所属课程未发布或学员无课程权益时无法读取。

视频页先验证登录与课程权益，再获取有效期两小时的播放入口；分段请求仍校验登录、权益和上架状态。播放器遇到过期提示时可重新打开。真机使用需要可访问的 HTTPS 服务地址和微信合法域名配置，实际解码效果还需使用真实视频在微信真机验证。

## 本次验证

自动化测试覆盖文字、PDF、Word、网页、视频导入、草稿发布、排序、课程权益、视频 Range 请求及撤权/下架后的访问拒绝。浏览器在隔离数据环境走通文字、Word、视频创建与排序保存；不向日常使用的数据库写入演示课程。
