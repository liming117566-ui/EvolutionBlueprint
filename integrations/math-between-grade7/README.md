# 数学之间 · 北师大七年级上册

沿用“几何之间”的侧栏、专题探索、收藏、学习足迹、资料预览与打印方式。原生 HTML / CSS / JavaScript，无构建步骤，无需安装 npm 依赖。

## 运行

在本目录运行 `node web/server.js`，访问 http://localhost:4175 。也可运行 `启动网站.ps1`。如果端口冲突，可在 PowerShell 中设置 `$env:PORT=4180` 后启动。服务器只监听本机地址。

## 内容

- 六章学习地图，29 个配套学习专题、58 道原创自测。
- 14 种交互演示，包括棱柱、展开图对应面、数轴、加法、乘方、科学记数法、代数式、规律、线段、角、多边形、方程、行程与统计。
- 348 份预置讲义，来自三套原始 DOCX，保留学生版与教师版。
- 原讲义中的公式和题图转换为图片；共 49,494 个去重图片资源，其中 43,967 个 Word 图元转换为 PNG。
- 收藏、掌握状态、最近学习和自测答案保存在当前浏览器；不需要账号，不上传学习记录。
- 自动组卷：六章范围、三档难度、选择/填空/解答题，可自定题量、分值、标题和时间，学生卷与答案分别打印。

## 自动组卷

打开侧栏“自动组卷”（`http://localhost:4175/#exam`）。可使用随堂小测、单元练习、期末综合三种预设，也可自行选章节、难度、各题型数量与分值。每份 1～60 题，每题型最多 30 题。默认综合卷 20 题、100 分、90 分钟。章节题量尽量均衡；题数不足以覆盖全部所选章节时随机选取部分章节。

点击“生成一份新试卷”应用设置；“同配置再出一份”沿用当前试卷的配置重新出题。答案默认隐藏，查看后仍可单独打印无答案的学生卷。打印采用 A4 纵向，浏览器打印窗口可另存为 PDF。设置和最近一份试卷只保存在当前浏览器。

题目来自 22 个参数化原创数学模型，覆盖三档计算与推理层次，配有答案解析；没有从 Word 讲义自动抽取题目。单卷题干去重，跨卷仍可能出现同类题，不保证所有题型或所有知识点都在一份卷中覆盖。适合随堂练习、单元巩固和综合复习，正式考试前请教师审题并调整分值。

## 阅读与打印

资料可按章节、套别、版本和类型筛选；搜索覆盖资料标题及部分知识点/题型标题。点击资料条目可在站内阅读，配对的教师版与学生版可相互切换。点击“打印资料”，等待图片加载完成后，在预览中点击“确认打印 / 另存为 PDF”。支持 A4 / Letter、纵向 / 横向。

使用者前台仅查看与打印开发者预置资料，无文件上传、修改或删除功能。服务器仅接受 GET / HEAD。普通网页无法阻止使用者通过浏览器保存已经显示的内容；这里的限制是产品界面和服务写入权限，不是 DRM。

网页阅读版保留正文、公式图、题图和表格，按屏幕重新排版，分页与字体可能不同于 Word。打印前检查预览；原始 DOCX 仍保留在项目原目录，未修改。学习提要、例题步骤与自测是配套学习内容，没有把原讲义题目自动伪装为可批改题库。

## 文件结构

| 路径 | 用途 |
| --- | --- |
| `web/index.html`、`web/styles.css` | 页面入口与响应式样式 |
| `web/app.js` | 路由、搜索、收藏、自测、学习记录、资料与打印 |
| `web/data.js`、`web/scenes.js` | 配套学习内容与交互模型 |
| `web/exam-engine.js`、`web/exam.js`、`web/exam.css` | 参数化组卷、配置与预览、独立打印排版 |
| `web/materials-data.js` | 348 份资料的元数据和搜索标题 |
| `web/materials/`、`web/media/` | 原资料阅读版和公式图片 |
| `web/reader.css` | 讲义阅读与打印排版 |
| `web/server.js` | 本机只读静态服务 |
| `tools/build_materials.py` | 从源 DOCX 重建资料阅读页和清单 |
| `tools/convert_metafiles.ps1` | 在 Windows 下用 GDI+ 将图元转换为 PNG |
| `tests/verify.cjs` | 课程、数学模型、资料资源完整性检查 |
| `tests/exam.cjs` | 随机题答案核验、满题量、章节均衡、答案与学生卷分离 |

## 维护

网站运行无需 Python；仅重建原资料时需要 Python 3，以及带 .NET / System.Drawing 的 PowerShell 7。重建顺序：先运行 `python tools/build_materials.py`，再运行 `pwsh -File tools/convert_metafiles.ps1`。网站只读取 `web/`，`work/` 中间文件不需要部署。

`node tests/verify.cjs` 检查学习内容、自测答案编号、关键数学演示结果和阅读版所有图片引用。部署静态网站时上传整个 `web/` 目录，开发者工具保留在本地。源码压缩包包含网页阅读版图片，不重复放入约 390 MB 的原始 Word 文件；重建时需要原目录中的 DOCX。

`node tests/exam.cjs` 额外核对 36,000 道随机题答案，并检查六章、三档难度下的单章节 60 题组卷、随机种子复现、题干去重、分值、无效配置与安全标题转义。安装了 npm 时也可用 `npm test` 一起运行两项检查。
