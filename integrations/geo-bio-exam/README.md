# 地生会考学习空间

沿用“几何之间”的侧栏、知识卡片、专题学习和本地学习记录方式，以当前目录四册人教版课堂笔记为资料来源。原生 HTML / CSS / JavaScript，无需安装依赖或执行构建。

网站面向地理、生物会考复习，当前开放生物板块；地理板块标记为“待定”，后续再确定内容与方案。更名沿用原有学习记录存储标识，保留当前浏览器中的收藏、笔记和进度。

## 打开

直接双击 `打开网站.html`。所有知识内容和原书页图均可离线使用。

推荐通过固定的本机地址使用，以稳定保留浏览器学习记录：

```sh
node web/server.js
```

打开 http://localhost:4174 。Windows 可运行 `启动网站.ps1`；已有 npm 时也可执行 `npm start`。

## 内容与功能

- 四册新版教材的完整常规课程目录；综合实践项目、课堂批注和附录保留在原书页图中。
- 每个知识专题包括三条提要、易混提醒、分步梳理或交互模型、一题自测，以及原书定位。
- 11种交互模型：细胞、显微镜、种子萌发、光合作用、呼吸、血液循环、尿液形成、反射弧、遗传方格、食物链能量、自然选择。
- 四册共535页原书页图，支持翻页、按PDF页码跳页、缩放和打印当前页。
- 站内搜索、收藏、掌握标记、个人笔记、随机自测、错题回顾与学习足迹。
- 复习冲刺打卡：7个任务覆盖66个生物知识点，每项配套6—10道概念练习；支持中途暂停、刷新续答、解析和错题联动。重点复习确认与当日练习都完成后可打卡，按北京时间统计连续与累计天数，同一天完成多个任务仍只计1天。地理计划暂不开放。
- 出卷中心：按教材和章节筛选，设置题量、名称和建议用时，随机抽题并打乱选项顺序；保存最近10份试卷，提供学生卷与答案解析卷独立打印，以及在线续答、交卷评分和错题联动。当前题库为66道单项选择概念题，单卷不重复，各题等权，满分100分。打印对话框可选择“另存为PDF”。
- 专题提要与个人笔记可打印；手机、平板和桌面布局自适应。

提要与自测是依据教材知识编写的学习辅助内容，不是原笔记逐字转写。模型中的概率、传递效率、相对速率等均标明假设，只用于理解原理。

## 文件

| 文件 | 用途 |
| --- | --- |
| `web/index.html` | 网站入口 |
| `web/styles.css` | 页面布局与打印样式 |
| `web/data.js` | 四册课程目录、学习提要与自测 |
| `web/scenes.js` | 11种模型和概念分步梳理 |
| `web/app.js` | 路由、搜索、阅读、自测、学习记录 |
| `web/sprint-core.js`、`web/sprint.js`、`web/sprint.css` | 冲刺计划、日期规则、断点练习与打卡界面 |
| `web/papers-core.js`、`web/papers.js`、`web/papers.css` | 组卷、在线作答批改、学生卷与答案解析打印 |
| `web/books.js` | 原书信息与页码偏移 |
| `web/pages/` | 535张原书页图，含课堂批注 |
| `web/server.js` | 仅监听本机的静态服务 |
| `tools/prepare_pages.py` | 从项目根目录PDF重新生成页图 |
| `tests/verify.cjs` | 课程数据、页图覆盖、模型概率校验 |

代码包已包含全部535张原书页图，运行网站无需原始PDF。原始PDF未放入代码包；只有使用 `tools/prepare_pages.py` 重新生成页图时才需要将对应PDF放到项目根目录。单独复制整个 `web/` 文件夹也可使用；勿漏掉 `pages/`。

## 学习记录

使用浏览器 localStorage 保存收藏、掌握状态、错题、作答统计和个人笔记。数据不上传，不跨设备同步。不同浏览器、不同访问地址、直接文件打开和本机服务之间的记录可能相互独立。清理站点数据会删除学习记录。

冲刺练习的题序、答案、进度、复习确认和打卡记录使用同一份本地学习数据保存。累计任务完成状态保留；再次打卡需要当天确认复习并完成一轮配套练习，不提供补签。当天尚未打卡时，连续天数保留至昨日，错过完整自然日后重新计数。

## 校验

```sh
node tests/verify.cjs
node tests/sprint.cjs
node tests/papers.cjs
```

也可执行 `npm test` 运行上述全部校验，无需安装依赖。

端到端交互检查另见 `tests/browser.cjs`、`tests/sprint-browser.cjs` 和 `tests/papers-browser.cjs`，需要可用的 Playwright 和 Chromium/Edge。
