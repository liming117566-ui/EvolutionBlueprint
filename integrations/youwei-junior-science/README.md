# 浙教版初中科学学习

面向备课与学生自学的静态学习网站，包含物理、化学、生物、地球与宇宙，以及共用探究与工程专题。

- 140 个学习单元，360 个学习目标。
- 783 道课程与看图练习，支持预习、复习、练习和订正。
- 752 个历史真题题号索引及本站原创解析。
- 32 套原创课程与解析材料，提供 PDF 和可编辑 HTML。

完整网站位于 `dist/`；首页会自动进入学习网页。无需登录，没有后台数据库或在线 AI 调用。学习记录保存在当前浏览器，可通过网站的 JSON 导出和导入迁移，不同设备不会自动同步。

## 内容边界

教材与第三方完整试卷原件不包含在公开仓库中，请通过网站中的原出处链接获取。本站内容不代表完整教材与中考原卷的穷尽覆盖；新九下、可靠的 2026 原卷和部分来源冲突仍待核验。自评和练习记录不代表已经掌握。

## GitHub Pages 部署

在仓库 **Settings → Pages** 选择 **Deploy from a branch → main → / (root)**。根目录的 `.nojekyll` 用于直接发布静态文件，`index.html` 会保留链接中的查询参数与课程位置，跳转到 `dist/`。

更新时先在原内容项目运行公开导出和学习流程检查，再将本仓库已验证的变更提交到 `main`。随后核对 GitHub Pages 部署状态、实际网页和资源；推送成功不等于部署成功。
