# 几何之间 · 交互数学实验室

把数学结论变成可以亲手探索的图形。

## 打开网站

- 最简单：双击当前文件夹中的 **打开网站.html**，无需安装依赖。
- 推荐：在 PowerShell 中运行 `./启动网站.ps1`，在浏览器访问 http://localhost:4173 。保持终端运行。也可以安装 Node.js 后执行 `node web/server.js`。
- 本地服务仅监听本机，不会发布到互联网。端口可用环境变量 `PORT` 调整。

## 已有功能

- 110 个专题图鉴：60 个几何模型、18 个动点最值模型、32 个函数专题；提供分类、关键词搜索及交互筛选。
- 18 个专题有参数演示，涵盖 16 种图形机制：双中点、双角平分线、倍长中线、勾股等积、中位线、圆周角、垂径、A 字相似、两点间最短、垂线段最短、单动点最值、将军饮马、一次函数面积、二次函数铅垂最值、反比例双曲线、反比例原点三角形、锐角三角函数、一次函数与方程不等式。
- 图形无需拖动。点击“换组条件”或调整参数，对比长度、角度、面积与函数值。
- 辅助线开关、图形重置、全屏、分步推导、选择题及即时反馈。
- 收藏、专题笔记、手动掌握标记、最近探索、分类进度。
- 学习记录以浏览器 localStorage 保存在本机；支持 JSON 导入合并与导出备份。
- 296 页原书正文支持站内翻页、页码选择及清晰原图查看；交界页可能包含相邻专题。
- 原书链接直接定位 PDF 页序号，书内页码 +9。扫描版 PDF 较大，首次加载可能需要时间；服务支持分段请求。
- 适配电脑、平板和手机；移动端可通过左上角菜单切换导航。

## 内容范围

110 个专题均可打开。18 个专题有参数演示，其余提供原创学习提示；全部专题均可在站内翻阅原书图解与例题。知识卡片中的小图用于表达主题，不作为所有具体模型的严格题图。完整适用条件、证明和例题应对照原书。原书正文 296 页已转换为站内可读页图，按专题分组，并保留原 PDF 链接；扫描内容未逐题转写为文本。

目录依据同文件夹内的 PDF；学习说明、小测和动态图形为本站编写。原书保留在原位置，未作改动。原书版权页为 2024 年 4 月第 1 版。

## 文件结构

- `web/index.html`：网站入口。
- `web/styles.css`：响应式样式。
- `web/data.js`：110 个专题索引、实验说明及小测。
- `web/scenes.js`：SVG 静态图形、参数演示与数学计算。
- `web/app.js`：路由、页面、搜索和学习记录。
- `web/server.js`：零依赖静态服务及 PDF 分段加载。

压缩包包含网站和全部 296 页阅读图，不包含原始大体积 PDF；站内阅读不受影响。要使用“打开完整 PDF”，请将原始 PDF 放在 web 文件夹的上一级。

没有构建步骤、账号要求或付费接口。网络仅用于加载可选字体；断网时会使用本机字体，学习功能仍然可用。直接打开文件与本地服务器、不同浏览器使用各自的本地记录，请通过导出和导入迁移。

## 资料与打印

左侧导航选择“资料与打印”，查看网站开发者统一发布的学习资料。

- 使用者可搜索、按分类筛选、预览和打印。前台不提供资料上传、修改、删除或独立下载入口，也不再读取浏览器中的个人资料库。
- 已收录 110 个专题的原书图解与例题，以及开发者发布的补充资料。专题讲义沿用书内页码，例如讲义 P.26—29，可填写 `26,28-29`；留空表示本讲义全部页面。交界页可能包含相邻专题。
- 可设置 A4 / Letter 及纵向 / 横向。点击“打印资料”生成站内打印预览，检查后点击“确认打印”，再在系统窗口选择打印机、份数和双面等设置。每次最多准备 100 页。
- 建议运行 `启动网站.ps1` 后访问 http://localhost:4173，并在 Chrome / Edge 中使用打印。
- 网站的资料服务仅支持 GET / HEAD，不提供公开写入接口。开发者通过下方本地工具更新源文件，发布权限取决于对项目或部署文件的访问权限。
- 浏览器的“另存为 PDF”和系统截图功能不受网页控制；去除下载按钮不代表可阻止使用者保存已显示的内容。
- PDF.js 及字库在本地打包，使用 Apache-2.0 许可证，详见 `web/vendor/LICENSE`。

## 开发者发布资料

在项目目录的 PowerShell 中运行：

```powershell
./发布开发者资料.ps1 -FilePath 'D:\资料\专题讲义.pdf' -Title '三角形专题讲义'
```

也可使用 Node.js：`node tools/publish-material.cjs "资料路径" "显示名称"`。支持 PDF、JPG、PNG、WebP、GIF、TXT 和 Markdown，单个文件不超过 100 MB。Office 文件需先导出为 PDF，加密 PDF 需先解锁。

工具将资料复制到 `web/materials/` 并更新 `web/materials-catalog.js`，刷新页面即可看到。部署时同步整个 `web` 文件夹；开发者工具位于网站目录以外，不部署为网页。移除补充资料时，由开发者从清单中移除对应条目后重新部署。示例原创记录单源文件位于 `开发者资料/专题练习记录单.txt`。

## 后续扩展

在 `data.js` 为专题指定 `scene`，并在 `scenes.js` 添加对应的几何约束与实时指标，即可扩充交互实验。上线前请确认原书及其扫描文件的传播授权；公开部署时可只部署原创交互网站，不上传原书 PDF。

## 校验

使用 Node.js 运行 `node tests/verify.cjs`，检查目录数量、73 组图形边界条件、最优路径、独立数学计算及 296 个正文页图。浏览器已实际验证搜索、原书翻页、收藏、笔记持久保存、小测反馈、掌握标记和移动布局。

运行 `node tests/materials.cjs` 检查已发布专题页图、讲义页码范围、前台无资料写入功能、开发者发布工具、重复与无效资料拦截、纸张设置。实际纸张输出由本机浏览器和打印机完成。
