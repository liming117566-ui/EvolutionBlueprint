---

这是一个面向 **AI 辅助自学初中数学** 的 Obsidian 学习库。它不是单纯的资料库，而是一个可长期运行的学习系统：

> 知识点定位 → 错题录入 → 错因分析 → 变式练习 → 间隔复习 → 数据统计 → 每周复盘

核心目标：

1. 用 AI 降低自学初中数学的整理成本。
2. 用错题和复习队列驱动学习，而不是盲目刷题。
3. 用 Dataview 自动统计薄弱点和学习进度。
4. 用统一字段和模板保证长期稳定。

## 快速开始

如果你只想记住一个流程：

1. 把错题图片放进 [[人教版初中数学AI学习库/00_Inbox/错题照片]]。
2. 对 AI 说：**"帮我处理最新错题图片"**。
3. 打开 [[人教版初中数学AI学习库/04_Dashboard/Home]] 做今日复习。
4. 每周打开 [[人教版初中数学AI学习库/04_Dashboard/WeakPoints]] 做复盘。

就够了。

> 详细规则和字段约束见 [[人教版初中数学AI学习库/RULES.md]]（面向 AI 的操作规范）。

## 1. 目录结构

```text
人教版初中数学AI学习库/
  00_Inbox/            临时入口：错题图片、临时笔记
  01_Knowledge/        人教版初中数学知识点库，默认只读
  02_ErrorBank/        错题库
  03_Practice/         变式题、专项练习、测试卷
  04_Dashboard/        仪表盘、复习队列、薄弱点、数据健康检查
  05_Assets/           图片、OCR、批注图、归档附件
  99_Backups/          修改备份和测试数据
```

| 目录 | 用途 |
|---|---|

| `01_Knowledge/` | 标准知识点库，普通错题和问答不直接修改 |

## 3. 总体学习流程

### 第一步：学一个知识点

打开对应知识点，例如：

- [[人教版初中数学AI学习库/01_Knowledge/01_七年级上册/01_第一章 有理数/07. 有理数的加减运算|有理数的加减运算]]

学习顺序建议：

1. 看"知识点定义"。
2. 看"核心内容"。
3. 看"关键要点"。
4. 做 3–5 道基础题。
5. 做 2–3 道提升题。
6. 错题进入 `02_ErrorBank/`。

### 第二步：录入错题

有两种方式。

#### 方式 A：用 QuickAdd 一键录入

在 Obsidian 命令面板中搜索：

```text
QuickAdd: 🚀 一键触发错题录入
```

或：

```text
QuickAdd: 📚 初中数学 AI 学习库
```

然后选择：

```text
➕ 新建数学错题
```

它会自动套用错题模板，并生成以下字段：

```yaml
area: 数与代数
knowledge:
  - "[[知识点页面]]"
error_type: 计算错误
status: 待复习
review_stage: 1
next_review: YYYY-MM-DD
review_dates:
  - 第 1 天
  - 第 3 天
  - 第 7 天
  - 第 14 天
```

#### 方式 B：让 AI 处理 Inbox 图片

把图片放入：

- [[人教版初中数学AI学习库/00_Inbox/错题照片]]

然后对 AI 说：

> 帮我处理 Inbox 里的错题图片，并生成错题页。

AI 应按 [[人教版初中数学AI学习库/RULES.md]] 执行：

1. 识别题目。
2. 定位知识点。
3. 分析错因。
4. 生成错题页。
5. 填写复习日期。
6. 生成变式题。
7. 移动或记录图片路径。
8. 验证 Dashboard 数据。

## 4. 图片管理流程

> 详细规则见 [[人教版初中数学AI学习库/RULES.md#13. 图片与附件管理规则]]。

为了避免图片越来越乱，所有图片统一进入 `05_Assets/`。

### 图片入口

| 场景 | 放到哪里 |
|---|---|
| 手动放入错题照片 | `00_Inbox/错题照片/` |
| Obsidian 中粘贴图片 | `05_Assets/01_RawImages/` |
| 已处理图片 | `05_Assets/02_ProcessedImages/` |
| OCR 文字 | `05_Assets/03_OCR/` |
| 批注图片 | `05_Assets/04_Annotated/` |

### 图片命名规范

```text
YYYY-MM-DD_年级_章节_知识点_序号.扩展名
```

示例：

```text
2026-04-30_七上_有理数_有理数加减_001.jpg
```

### 错题页中记录图片路径

frontmatter 中使用完整路径（方便 Dataview 查询）：

```yaml
source_image: 人教版初中数学AI学习库/05_Assets/02_ProcessedImages/2026-04-30_七上_有理数_有理数加减_001.jpg
ocr_text: 人教版初中数学AI学习库/05_Assets/03_OCR/2026-04-30_七上_有理数_有理数加减_001.md
annotated_image: 人教版初中数学AI学习库/05_Assets/04_Annotated/2026-04-30_七上_有理数_有理数加减_001.png
```

正文中嵌入图片：

```markdown
![[2026-04-30_七上_有理数_有理数加减_001.jpg]]
```

## 5. 错题字段说明

> 完整字段约束（允许值、更新规则）见 [[人教版初中数学AI学习库/RULES.md#6. 错题字段规范]]。

每道错题都应包含统一字段，方便自动统计。

| 字段 | 说明 | 允许值概览 |
|---|---|---|
| `grade` | 年级，如 七年级上册 | — |
| `chapter` | 章节，如 第一章 有理数 | — |
| `area` | 知识模块 | 数与代数 / 图形与几何 / 统计与概率 / 综合与实践 |
| `knowledge` | 关联知识点（wikilink 列表） | — |
| `error_type` | 主要错因 | 概念不清 / 方法不会 / 计算错误 / 审题失误 / 书写不规范 |
| `secondary_error_type` | 次要错因，可空 | 同上 |
| `difficulty` | 题目难度 | 易 / 中 / 难 |
| `mastery` | 掌握程度 | 未掌握 / 基本掌握 / 已掌握 |
| `status` | 复习状态 | 待复习 / 复习中 / 已掌握 / 需重做 |
| `review_stage` | 当前复习轮次 (1/2/3/4) | 1 / 2 / 3 / 4 |
| `next_review` | 下一次复习日期 | YYYY-MM-DD |
| `review_dates` | 计划复习日期列表 | YYYY-MM-DD 数组 |
| `last_review` | 上一次复习日期 | YYYY-MM-DD，可为空 |
| `attempt_count` | 重做次数 | 整数，默认 0 |
| `review_result` | 上次复习结果 | 通过 / 犹豫 / 错误 |
| `source_image` | 原图路径（完整） | 见图片管理 |
| `ocr_text` | OCR 文本路径 | — |
| `annotated_image` | 批注图路径 | — |

### 错因分类

详见 [[人教版初中数学AI学习库/RULES.md#5. 错因分类规则]]。

## 6. 每日使用方法

每天打开：

- [[人教版初中数学AI学习库/04_Dashboard/Home]]

按顺序做：

1. 查看"今日待复习"。
2. 先复习到期错题。
3. 对 `需重做` 的题重新做一遍。
4. 学习一个新知识点。
5. 做几道练习题。
6. 新错题录入 `02_ErrorBank/`。
7. 查看 [[人教版初中数学AI学习库/04_Dashboard/DataHealth]] 是否有异常数据。

## 7. 每周复盘方法

每周日打开：

- [[人教版初中数学AI学习库/04_Dashboard/WeakPoints]]
- [[人教版初中数学AI学习库/04_Dashboard/ReviewQueue]]
- [[人教版初中数学AI学习库/04_Dashboard/LearningProgress]]

然后使用 QuickAdd：

```text
QuickAdd: 📚 初中数学 AI 学习库 → 📆 新建每周复盘
```

或者对 AI 说：

> 根据本周错题、WeakPoints 和 ReviewQueue，帮我生成每周复盘和下周计划。

复盘重点：

1. 本周新增错题数量。
2. 薄弱知识点 Top 3。
3. 主要错因分布。
4. 哪个模块最弱：数与代数 / 图形与几何 / 统计与概率。
5. 下周复习和练习安排。

## 10. 数据健康检查

定期查看：

- [[人教版初中数学AI学习库/04_Dashboard/DataHealth]]

重点检查：

1. 有没有错题没有关联知识点。
2. 有没有错题缺少 `error_type`。
3. 有没有错题缺少 `next_review`。
4. 有没有错题缺少 `area`。
5. 有没有错题缺少 `review_stage`。
6. `status`、`mastery`、`area` 是否写错。
7. 有没有缺少 `source_image` 的错题。
8. Inbox 或 RawImages 是否堆积了未处理图片。

## 11. 推荐 AI 指令

### 处理错题图片

```text
帮我处理 00_Inbox/错题照片 里的最新错题图片，生成错题页，关联知识点，并生成 3 道变式题。
```

### 完善错题解析

```text
请根据 RULES.md 完善这道错题的正确解答、错因分析和变式题。
```

### 每日复习

```text
请根据 ReviewQueue 告诉我今天要复习哪些错题，并按优先级排序。
```

### 每周复盘

```text
请根据 WeakPoints、ReviewQueue 和 LearningProgress 生成本周复盘和下周学习计划。
```

### 数据健康检查

```text
请检查 DataHealth 中暴露的问题，并帮我修复字段缺失或异常的错题。
```

## 12. 维护原则

> 详细安全规则见 [[人教版初中数学AI学习库/RULES.md#16. 安全规则]]。

1. `01_Knowledge/` 默认不修改。
2. 错题必须进入 `02_ErrorBank/`。
3. 图片必须进入 `05_Assets/` 统一管理。
4. 每道错题必须关联至少 1 个知识点。
5. Dashboard 尽量通过 Dataview 自动统计，不手工维护。
6. 批量修改前先备份到 `99_Backups/`。
7. 测试数据必须含 `TEST` 或 `模拟测试`，测试后移动到 `99_Backups/测试数据/`。
