# AI命令：每周复盘

> 使用 Skill：`rj-junior-math-ai-learning`

请根据本周错题、[[人教版初中数学AI学习库/04_Dashboard/WeakPoints]]、[[人教版初中数学AI学习库/04_Dashboard/ReviewQueue]] 和 [[人教版初中数学AI学习库/04_Dashboard/LearningProgress]]，生成每周复盘和下周学习计划。

要求：

1. 总结本周新增错题数量。
2. 给出薄弱知识点 Top 3。
3. 给出薄弱模块：数与代数 / 图形与几何 / 统计与概率 / 综合与实践。
4. 总结主要错因。
5. 生成下周复习计划和练习建议。
6. 如需要，创建或更新本周复盘笔记。
