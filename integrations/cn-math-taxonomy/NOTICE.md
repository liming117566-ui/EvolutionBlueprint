# 数学知识图谱集成

来源：cn-math-taxonomy，https://github.com/xiaoyang111222/cn-math-taxonomy

来源提交：af81f2fd438e44cfeb0406cf3ce3680f88f6508d。使用 GitHub 提供的该提交源码归档导入。

本模块保留上游页面配色、CSS、知识图谱、题库、自适应诊断、学科切换、孩子档案与本机诊断记录。集成修改：移除首页、知识图谱、诊断、档案及历史页的“关于”导航链接；将首页内联重定向脚本移至同源文件以适应主服务的内容安全策略；为离线缓存增加独立命名空间和路径范围；关闭指向上游作者服务的访问统计上报。

进化蓝图中的板块名称为「中小学高中知识图谱」。各学科共用的诊断结果页（包括“先看一遍演示”）已移除「生成分享图」和「导出 JSON」按钮及事件实现，不再加载对应分享图脚本；诊断、结果分析、打印、重新开始和撤销作答保留。
